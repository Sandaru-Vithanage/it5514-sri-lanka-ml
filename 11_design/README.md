# Selected UI and verification evidence

The student selected **Option 1 — Ocean Observatory**, the first displayed AI-generated design concept. `reference-option-1.png` is a visual concept, not a deployed screenshot, experimental figure, or source of numerical chart coordinates. Actual interface plots are computed from the saved model/API values; this corrects illustrative marker placement in the concept.

The implementation uses a navy/cyan workspace, an input inspector, persistent navigation, real uncertainty plotting and the existing methodological disclosures. No decorative raster artwork was needed; fonts and Phosphor icons are bundled from their licensed packages. The selected concept was generated using the built-in image-generation tool with a captured screenshot of the previous interface as a content reference.

`qa/` contains real browser captures and source/implementation comparison sheets. `design-qa.md` at the project root records desktop and phone checks, issues found and fixed, and the final acceptance status. Functional checks use the real Python GPR and recorded evidence, not mocked prediction responses.

The model, numerical experiment results, data splits and algorithm conclusions are unchanged by this frontend revision. Third-party software notices and reproducible build instructions are in `03_code/frontend/`.
